# Mac apps by Marco Sebastian

Small tools for everyday use on your Mac. Find the collection at [marcosebastian.com/apps](https://marcosebastian.com/apps).

| App | Version | What it does |
| --- | --- | --- |
| Git Action Glass | 1.9.2 | Follow GitHub Actions, job steps, and pull request checks from a floating panel. |
| Game Shade | 1.0.1 | Dim your other displays while you play, and restore them when you switch away. |
| Codex Usage | 1.6.1 | See your Codex limits, reset times, and running tasks from the menu bar. |

## Download and install

Choose your app from [Releases](https://github.com/marcosebastian/mac-apps/releases), download its ZIP, unzip it, and move the app to Applications. Each ZIP includes a Read Me with setup instructions.

All three apps support Apple silicon and Intel Macs running macOS 14 or later. Git Action Glass uses your own GitHub account. Codex Usage requires Codex signed in with ChatGPT. Game Shade is intended for multiple displays.

The apps are Developer ID signed by Marco Lopez and notarized by Apple. Their notarization tickets are attached. Each release includes a SHA-256 checksum file for its ZIP.
